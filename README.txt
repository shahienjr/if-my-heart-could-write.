# If My Heart Could Write

A responsive, vintage love-letter website.

## Add your paragraphs

Open `index.html` and replace these placeholders with your five original paragraphs, in order:

1. `[PASTE YOUR FIRST PARAGRAPH HERE]`
2. `[PASTE YOUR SECOND PARAGRAPH HERE]`
3. `[PASTE YOUR THIRD PARAGRAPH HERE]`
4. `[PASTE YOUR FOURTH PARAGRAPH HERE]`
5. `[PASTE YOUR FIFTH PARAGRAPH HERE]`

## Add photos

Replace each `<div class="photo-placeholder">...</div>` with an image tag, for example:

```html
<img src="photo-1.jpg" alt="A meaningful photograph of us">
```

Put your images in the same folder as `index.html`, or use an image URL.

## Add music

Place an instrumental audio file named `music.mp3` in the same folder as `index.html`.
If you do not add it, the Music button will simply show “Add music.mp3”.

## Publish and get a link

### Easiest: Netlify Drop

1. Put `index.html`, `styles.css`, `script.js`, your photos, and `music.mp3` in one folder.
2. Go to https://app.netlify.com/drop
3. Drag the entire folder onto the page.
4. Netlify gives you a live link such as `https://your-site-name.netlify.app`.
5. In Netlify, open **Site configuration → Change site name** to choose a custom name.

### Free alternative: GitHub Pages

1. Create a GitHub account and a new public repository, for example `if-my-heart-could-write`.
2. Upload `index.html`, `styles.css`, `script.js`, and your photo/music files.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait a minute or two; GitHub gives you a link like:
   `https://your-username.github.io/if-my-heart-could-write/`

## Local preview

Double-click `index.html`, or right-click it and choose “Open with” your browser.
